# Capacidades avanzadas — evidencia de A1.5 y propuesta para A1.6

## Alcance y método

Lectura local de las tres colas prioritarias, con `scripts/PrinterCapabilitiesProbe` (`dotnet run --project scripts/PrinterCapabilitiesProbe -c Release`). Consulta PrintCapabilities XML, proyección pública System.Printing, PrintTicket de usuario/predeterminado y copia DEVMODE con `DocumentProperties(DM_OUT_BUFFER)`. No modifica preferencias, no usa `DM_IN_BUFFER`, `SetPrinter`, `Commit`, RAW ni comandos de fabricante. El JSON registra su fecha UTC y oculta el identificador WSD.

Evidencia: [capabilities-readonly.json](a15-audit/capabilities-readonly.json). Es lo anunciado por los controladores instalados, no una certificación física ni una prueba de escritura. Las colas Star y Brother reportaban Offline; POS80 reportaba cero flags, que no confirma disponibilidad. Los namespaces privados y los nombres de opción necesitan documentación y versión del proveedor antes de configurarlos.

## Matriz real

Clasificación: **A** API pública detectable y configurable por trabajo (con validación del controlador; no se ensayó escritura en esta investigación); **B** detectable, sin modificación segura validada; **C** documentada mediante utilidad/preferencias oficiales; **D** no soportada o no verificable con esta evidencia.

| Capacidad | Star BSC10 | POS80 Printer (driver POS80) | Brother HL-1210W series |
| --- | --- | --- | --- |
| Tamaño de papel | A: Letter/A4 y tamaños privados de recibo 72/64/50.8/45 mm; GDI admite los papeles anunciados | A: cuatro formularios privados; la proyección pública no los devuelve, usar nombres GDI y no asumir A4 | A: papel anunciado; algunas opciones genéricas exceden el hardware, validar por modelo |
| Orientación | A: vertical/horizontal | A: vertical/horizontal | A: vertical/horizontal |
| Resolución/calidad | B: opción privada XNormalYNormal; proyección de resoluciones vacía | B: 203×203, sin alternativas anunciadas; no equivale a control de densidad | B: anuncia 300/600/1200 dpi y calidad Normal; no se validó un nuevo selector ni su equivalencia física a HQ1200 |
| Densidad | C: utilidad BSC10 oficial documentada; ausente del XML leído | D: no aparece; fabricante/modelo del equipo no identificados | B: `brpsk:JobDensityAdjustment` PrinterDefault/Manual y `JobTonerTranscriptionLevel`; no editar sin contrato del driver. Alternativa: preferencias oficiales |
| Velocidad | D: no expuesta en el XML consultado; velocidad nominal no implica ajuste | D: no expuesta; no enviar ESC/POS genérico | D: no se observa ajuste de velocidad por trabajo |
| Corte de papel | D en API leída: no aparece. BSC10 tiene cortador; revisar preferencias/utility de ese driver antes de ofrecer una opción | D: nombre POS80 no demuestra que el modelo tenga cortador ni su protocolo | D: no aplica cortador de recibos; opciones CutOutLine son líneas de guía, no corte físico |
| Ahorro/calidad privada | D: sin control adicional verificado | D: sin control adicional verificado | B: EconomyMode, GraphicsQuality, mejora de fijación y curvatura anunciadas como extensiones Brother |

Ninguna opción privada pasa de B a A por el mero hecho de aparecer en XML. El proyector System.Printing omite algunos medios privados: Star muestra muchos formularios en XML pero solo Letter/A4 en `PageMediaSizeCapability`; POS80 devuelve la colección pública vacía. Tampoco anunciar dúplex o A3 prueba que Brother tenga dúplex automático o acepte A3. Deben contrastarse con el manual y con el driver exacto.

DEVMODE leído: Star 220 bytes públicos + 860 privados; POS80 220 + 0; Brother 220 + 3188. No se decodificaron los bytes privados. Que POS80 no devuelva datos privados no demuestra que todas sus preferencias sean públicas ni que el dispositivo carezca de ajustes persistentes.

## APIs y fabricante

[Print Schema de Microsoft](https://learn.microsoft.com/en-us/windows/win32/printdocs/printschema) distingue PrintCapabilities (opciones) y PrintTicket (intención), y permite extensiones privadas. Para un proveedor futuro, validar la combinación y el alcance antes de convertir ticket a DEVMODE y pasar por el transporte GDI; no cambiar el motor actual para fingir soporte universal.

[DocumentProperties](https://learn.microsoft.com/en-us/windows/win32/printdocs/documentproperties) permite obtener el tamaño total y copiar el DEVMODE vigente. Los campos públicos se interpretan según dmFields; los datos extra son del controlador. Esta lectura usa solo salida a memoria y no presenta diálogos ni escribe configuración.

[Soporte oficial BSC10](https://starmicronics.com/support/products/bsc10-support-page/) ofrece instalación Windows y JavaPOS. La [guía oficial regional de densidad](https://starmicronics.co.th/wp-content/uploads/2020/07/How-to-download-_-install-utility-_-change-density-for-BSC10-Model.pdf) documenta el uso de la utilidad BSC10. La [página del producto](https://starmicronics.com/product/bsc-10-thermal-printers/) describe emulación ESC/POS y OPOS: eso no autoriza reutilizar comandos de otro modelo ni garantiza un SDK Windows compatible con la instalación actual. La integración directa exige manual de comandos, revisión de firmware y pruebas específicas. Densidad no se traduce automáticamente a temperatura del cabezal.

[Manuales oficiales Brother HL-1210W](https://support.brother.com/g/b/sp/manualtop.aspx?c=gb&lang=en&prod=hl1210w_eu_as) y sus preferencias nativas son la alternativa para densidad, ahorro de tóner y calidad. La lectura local confirma extensiones Brother; no se encontró en esta investigación un contrato público específico que permita escribirlas de forma segura. No se extrapolan SDK de etiquetadoras Brother a esta láser.

POS80 es una etiqueta de driver, insuficiente para identificar fabricante y revisión de hardware. Existen [descargas POS-80 de Xprinter](https://www.xprintertech.com/download/pos-80), pero no hay evidencia de que este equipo sea Xprinter. No se descarga ni usa su SDK como si lo fuera. Identificar etiqueta física, proveedor y versión del driver antes de investigar densidad, velocidad o cortador.

Alternativa disponible en la interfaz: Configuración de Windows → Impresoras y escáneres → impresora concreta → Preferencias de impresión. El usuario debe saber que guardar allí puede afectar trabajos futuros; NPB no escribe esas preferencias automáticamente.

## Siguiente entrega
